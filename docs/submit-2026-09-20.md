## Problem statement (draft)

HR teams run onboarding as PDFs and slide decks. New hires forget policies and team rituals before week one ends. First Quest turns interview answers plus fictional HR documents into a playable 2D RPG backed by validated GamePack JSON, so onboarding becomes something people **play** instead of only read.

Public demo uses **Neulbom Labs** only. No real customer data in the repo or live URL.

## AI tools used (draft)

- Cursor Agent (Composer / Grok) for implementation and verification loops
- GamePack schema authored with Zod as single source of truth for Phaser runtime
- Planned PR-04+ async generation pipeline with LLM steps guarded by schema validation
