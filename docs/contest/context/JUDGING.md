## Live URL requirements

1. Idea must be a **actually working, deployed** service. (Landing 과제 제출)
2. Web is **권장**. (Landing FAQ 앱)
3. Hosts such as Vercel / Railway are allowed. (Landing FAQ)
4. During **심사 기간**, the link must be **normally reachable**. If judges cannot access it, the entry **may be excluded**. (Landing FAQ “배포 링크”)
5. **Unvetted installers (APK, exe, etc.) are not allowed** — site is public, not just judges. (Landing FAQ 앱)
6. Mobile: Play Store / App Store link if officially listed. Desktop: official store (e.g. Microsoft Store) if listed. Else ship a **web demo of core features** as the service URL. (Landing FAQ)
7. Store builds must already be **approved and public at submit time**, and stay public **2026-09-21 through 2026-10-17**. (Landing FAQ 앱)

- Generic “심사 기간 동안 접속” FAQ does **not** restate end-date. Treat **10/17** as the safer official keep-alive for store apps; web FAQ is only “during judging.” Operator should keep the production URL up through Demo Day.
