## Eligibility

- Age **19+** on application date
- University students, graduates, general public; employees/freelancers/sole proprietors if eligible
- **Individual or team up to 5**
- **Free** entry
- **No topic restriction** if AI solves a real problem or creates new value
- Existing projects, OSS, external APIs, generative AI allowed if **copyright, license, and employer rules** respected

Source: VentureSquare 1109725 (*secondary*, 2026-08-31)
